# Telegram Mini App — «Мои пары»

Это первая автономная версия приложения с:
- красивым мобильным интерфейсом;
- календарём;
- кнопками «Вчера / Сегодня / Завтра»;
- расписанием по конкретным датам;
- поддержкой темы Telegram;
- готовностью к запуску внутри Telegram Mini App.

## Быстрый запуск

1. Откройте `index.html` в браузере — приложение уже работает локально.
2. В `index.html` найдите `const schedule = {...}` и замените тестовые пары на свои.
3. Чтобы открыть приложение внутри Telegram, файл нужно разместить на HTTPS-хостинге.
4. После этого URL приложения можно указать в @BotFather при настройке Mini App.

## Важно

Эта версия специально сделана без базы данных и сервера: расписание хранится прямо в JavaScript. Это удобно для первого прототипа. Позже можно подключить Google Sheets/таблицу, базу данных или админ-панель, чтобы менять расписание без редактирования кода.
